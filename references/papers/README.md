# Source Papers

Drop PDFs here. Everything in this directory except this README is gitignored,
because publisher PDFs are copyrighted and must never be pushed to a public
repository.

Filenames do not matter. Anything readable will be found.

Free preprint versions exist for some of these. The KU Leuven discussion paper
version of Cherchye et al. is at
<https://feb.kuleuven.be/drc/Economics/research/dps-papers/dps12/dps1215-new2.pdf>
and an IFN working paper version of Hjertstrand, Swofford and Whitney is on
EconStor. The published versions are preferred where the algorithm is concerned,
since working paper formulations sometimes differ from what was finally printed.
